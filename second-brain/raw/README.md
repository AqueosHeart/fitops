# Raw Notes Guide

Place only material that has already been read, written, or meaningfully reviewed by the project owner in this folder.

Recommended locations:

- `01-articles/` for annotated articles
- `02-books/` for book notes
- `03-podcasts/` for podcast notes
- `04-videos/` for video notes
- `05-social/` for reviewed social posts
- `06-flash_notes/inbox/` for original project ideas awaiting review

Do not place unread link dumps, copied private records, API keys, passwords, tokens, customer information, or copyrighted full-text sources here.
