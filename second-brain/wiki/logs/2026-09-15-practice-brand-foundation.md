# Practice Athletic Club Brand Foundation

## User goal

Create a complete identity for the fictional gym before designing or implementing its website or booking application.

## Decisions

- The gym's public-facing name is **Practice Athletic Club**.
- `FitOps` remains the repository and internal project codename.
- The current scope is brand identity only: strategy, voice, moodboards, logo, color, typography, visual language, usage rules, brand-guide artifact, and production assets.
- Website implementation, application code, UI component engineering, Storybook, and automated token pipelines are excluded from this stage.
- The working brand character is disciplined, precise, welcoming, and energetic without macho, militaristic, or transformation-hype conventions.
- `Progress is a practice.` remains a working tagline and is not yet approved.

## Evidence created

- `docs/brand/brand-foundation.md`
- Product-requirement clarification distinguishing the public brand from the repository codename
- Updated project, sprint, board, index, critical-facts, and activity-log context

## Unresolved work

- Create three differentiated visual territories.
- Select one territory before finalizing the logo, palette, typography, and visual system.
- Perform manual trademark and relevant jurisdiction checks before treating the name as commercially cleared.
