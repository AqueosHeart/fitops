# FitOps web app

This is the Next.js application for FitOps. For a clean setup—including local PostgreSQL, private environment variables, Prisma migrations, fictional seed data, and verification—follow the repository's [Local development guide](../docs/local-development.md).

After setup, run `npm run dev` from this directory. Do not commit `.env`, `.env.local`, database dumps, or Docker volume contents.
