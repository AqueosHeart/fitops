# Brand Font Sources

## Mona Sans

- Source: official [Mona Sans repository](https://github.com/github/mona-sans)
- Selected use: Practice Athletic Club wordmark construction and future brand/interface typography system
- License: SIL Open Font License 1.1, stored at `mona-sans/OFL.txt`
- Variable font file: `mona-sans/MonaSans-Variable.ttf`
- Wordmark axes: `wdth 94`, `wght 800`, `opsz 72`

The logo is supplied as outlined SVG artwork and must not be recreated by typing the name. Mona Sans remains editable for future headline, schedule, label, and body-copy rules.
